# Gabinete Digital

Protótipo navegável de um sistema para gabinete de vereador.

- **Painel:** fase eleitoral atual, contagem até a eleição de 2028, agenda do dia, tramitação dos projetos e demandas dos moradores.
- **Projetos de lei:** a ideia vira um dossiê com legislação, jurisprudência, análise de competência e minuta editável. Segure o botão para protocolar.
- **Agenda:** semana com compromissos, presença por bairro e demandas.
- **Comunicação:** calendário de posts conferido contra as regras eleitorais (Lei 9.504/1997).

Site estático: um único `index.html`, sem build. Os dados são de exemplo e ficam salvos só no navegador de quem usa.

## Publicação

Publicado pelo Netlify a partir da branch `main`. Não há comando de build; o diretório publicado é a raiz do repositório.
